Slide 03 — Konteks Nyata

Bilangan Bulat di Sekitar Kita

Bilangan bulat bukan cuma angka di buku. Mereka ada di mana-mana! Positif, nol, dan negatif membantu kita mengukur hal-hal berlawanan.

🌡️

Suhu Udara

0°C adalah titik beku air. Di atas 0 (positif) hangat, di bawah 0 (negatif) membeku!

🏦

Uang & Utang

Memiliki uang (positif), tidak punya uang (nol), dan berutang (negatif).

🏢

Lantai Gedung

Lantai dasar adalah 0. Lantai 1, 2 (positif) di atas, basement -1, -2 (negatif) di bawah tanah.

🌊

Kedalaman Laut

Permukaan laut adalah 0 meter. Titik penyelaman di bawah permukaan diukur negatif.

Apa itu Bilangan Bulat?

Bilangan bulat adalah himpunan bilangan yang terdiri dari bilangan bulat positif, nol, dan bilangan bulat negatif. Bilangan bulat tidak memiliki bentuk pecahan atau desimal.

-1, -2, -3, ...

Di kiri nol

Nol (0)

0

Netral / Tengah

Positif (+)

1, 2, 3, ...

Di kanan nol

{ ..., -3, -2, -1, 0, 1, 2, 3, ... }

Contoh Kehidupan Sehari-hari

🏦 Kasus 1: Tabungan

Ali punya tabungan Rp 50.000 (ditulis +50.000). Ia membeli mainan Rp 70.000, sehingga ia berutang Rp 20.000 (ditulis -20.000).

🚗 Kasus 2: Jarak

Kota A ke Utara bernilai positif, ke Selatan bernilai negatif. Jika berjalan 5km ke Utara (+5), lalu 8km ke Selatan (-8), posisinya berada di -3km.

⚽ Kasus 3: Skor Pertandingan

Skor kemenangan diberi nilai positif (+1), kekalahan negatif (-1). Tim B menang 3, kalah 2, total skor = +1.

Aturan Operasi Hitung

➕ Penjumlahan & Pengurangan

  • (+) + (+) = positif (jumlahkan)
  • (-) + (-) = negatif (jumlahkan)
  • Tanda berbeda -> Kurangi, ikut tanda terbesar
  • Contoh: -5 + 3 = -2
  • Contoh: 4 - (-2) = 4 + 2 = 6

✖️ Perkalian

  • (+) × (+) = (+) Positif
  • (+) × (-) = (-) Negatif
  • (-) × (+) = (-) Negatif
  • (-) × (-) = (+) Positif
  • Contoh: -4 × -3 = 12

➗ Pembagian

  • Aturan tanda sama seperti perkalian
  • (+) : (+) = (+)
  • (+) : (-) = (-)
  • (-) : (-) = (+)
  • Contoh: -15 : 3 = -5

💡 Clue Pindah Ruas:
• Jika suatu ruas dipindahkan ke ruas lain, tandanya berubah (positif jadi negatif, negatif jadi positif).
• Contoh: 2 + x = -5 -> Angka 2 pindah ke kanan jadi -2, sehingga x = -5 - 2 = -7.
• Jika ada bentuk seperti 2x, itu artinya 2 dikali x. Untuk mencari x, bagi kedua ruas dengan angka di depan x.
